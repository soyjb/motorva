## Conservative generation matching (US model years)

- Camry: 2018–2024, example shows a 2018 SE. The [2025 Camry starts the ninth generation](https://pressroom.toyota.com/toyota-unveils-the-powerful-and-purely-hybrid-next-generation-camry/).
- Civic: 2016–2021, example shows a 2020 Si sedan. The [2022 Civic starts the eleventh generation](https://hondanews.com/en-US/releases/release-53541be6030b25a47a2899aba12aa1f6-2022-honda-civic-sedan-press-kit).
- Mustang: 2015–2023, example shows a 2018 GT coupe. The [2024 Mustang starts the seventh generation](https://media.ford.com/content/fordmedia/fna/ca/en/news/2022/09/16/2024-ford-mustang-reveal.html).

Matching uses exact model names and bounded years. A Mustang Mach-E,
Civic Type R, or another generation uses the illustration unless the user
adds their own photo. These examples do not identify an exact body style
or factory configuration.
