# Motorva frontend

Digital Garage using React, TypeScript, App Router, Tailwind CSS, and ESLint.
Choose a year, make, and model using the free NHTSA vPIC directory, then add
mileage. Manual entry is available for unlisted vehicles, years before 1996,
or an unavailable directory. No API key, signup, or paid service is required.
The make list covers cars, trucks, and SUVs across years; models are filtered
by the selected year and make. The directory does not provide exact vehicle
photos, paint colors, trim catalogs, or parts-fitment guarantees.

Vehicles are saved in this browser's local storage and remain after reloads. They are
not synced to an account or the backend; clearing site data removes them.
Use **Remove vehicle** on a card, then confirm the named vehicle to delete it
from this browser's saved garage. **Keep vehicle** or Escape cancels removal.

Matching Camry (2018–2024), Civic (2016–2021), and Mustang (2015–2023) cards
show locally hosted, credited stock examples. These represent a generation,
not the exact year, trim, body style, or paint color. Other vehicles retain
the illustration. Photo licenses and original sources are listed in
`public/vehicles/ATTRIBUTION.md` and linked on each stock-photo card.

Add an optional photo with a new vehicle or use **Add your photo / Change
photo** on an existing card. JPG, PNG, and WebP files up to 10 MB are resized
to at most 1200×800 and compressed as JPEG (at most 450,000 data-URL
characters) before local saving. Canvas re-encoding drops source metadata.
Photos stay in this browser and are not uploaded to a server. If storage
is full, saving fails visibly and the existing garage remains unchanged.
**Use default image instead** restores the stock photo or illustration when
you save. Closing or cancelling a photo dialog leaves the saved photo intact.

Use Node.js 22.13+ (Node 22 LTS) or a newer supported LTS version and npm.

From this directory:

```powershell
npm ci
npm run dev
```

Open http://localhost:3000. No environment variables or backend connection
are required.

Validation and production commands:

```powershell
npm run lint
node --experimental-strip-types --test src/lib/vehicles.test.mjs src/lib/vehicle-catalog.test.mjs src/lib/stock-photos.test.mjs
npm run build
npm start
```

- `src/app/page.tsx`: home route.
- `src/app/garage.tsx`: garage cards, add-vehicle dialog, and browser storage.
- `src/lib/vehicles.ts`: vehicle validation and saved-data parsing.
- `src/app/vehicle-fields.tsx`: dependent year/make/model picker and manual fallback.
- `src/lib/vehicle-catalog.ts`: public NHTSA lookups, response validation, and session make caching.
- `src/app/layout.tsx`: root HTML layout and metadata.
- `src/app/globals.css`: Tailwind import and basic global styling.
- `public/`: future static assets.
- `tsconfig.json`: strict TypeScript configuration; `@/*` maps to `src/*`.
- `eslint.config.mjs`: Next.js and TypeScript lint rules.
- `next.config.ts`: Next.js configuration and Tailwind CSS Turbopack loader.
- `package.json` / `package-lock.json`: npm scripts and locked dependencies.
- `next-env.d.ts` / `.next/`: generated Next.js types and build output; ignored
  by Git and regenerated by Next.js.

The frontend is separate from the Spring Boot backend. The garage currently
stores vehicle details, odometer readings, and service history in this browser;
account sync is not connected yet.

# Vehicle details

Choose **View vehicle** in the garage to open `/vehicles/[id]`. Edit the year,
make, model, or mileage; corrections may decrease mileage. Edits preserve the
latest saved photo and other vehicles. Missing vehicles and unavailable or corrupt
browser storage show a recovery message without replacing saved data.

## Service history

On a vehicle page, choose **Add service** to record completed work, date,
mileage, optional USD cost, and notes. Records can be edited or removed with
confirmation and appear newest first. Historical service mileage does not
change the current odometer. Costs are stored as integer cents; an empty cost
is distinct from a free service. Existing garages without history still load.

Run service validation tests with:

```powershell
node --experimental-strip-types --test src/lib/services.test.mjs
```

## Maintenance reminders

Set a date, mileage target, or both on the vehicle page. The first reached
target determines status: past targets are overdue, exact targets are due now,
and targets within 30 days or 500 miles are due soon. Dates use the browser's
local calendar day and refresh each minute or when the window regains focus.
Schedules are entered by the user; Motorva does not infer manufacturer intervals.
Complete, reopen, edit, or remove reminders. **Mark completed** opens a form
prefilled with today's date and the current mileage; optional cost and notes
can be included. Saving creates the service record and completes the reminder
in one storage write. Canceling changes neither. Completion uses the actual
service date and does not change the odometer. Reopening or removing a reminder
keeps its history; completing a reopened reminder records another service.
Reminders are shown in the app only, with no
email or push delivery. Legacy saved garages remain compatible.

```powershell
node --experimental-strip-types --test src/lib/reminders.test.mjs
```
