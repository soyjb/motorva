# Motorva frontend

Minimal Next.js foundation using React, TypeScript, App Router, Tailwind CSS,
and ESLint. The home page is a Motorva placeholder.

Use Node.js 22.13+ (Node 22 LTS) or a newer supported LTS version and npm.

From this directory:

```powershell
npm ci
npm run dev
```

Open http://localhost:3000. No environment variables or backend connection
are required.

Validation and production commands:

```powershell
npm run lint
npm run build
npm start
```

- `src/app/page.tsx`: home route.
- `src/app/layout.tsx`: root HTML layout and metadata.
- `src/app/globals.css`: Tailwind import and basic global styling.
- `public/`: future static assets.
- `tsconfig.json`: strict TypeScript configuration; `@/*` maps to `src/*`.
- `eslint.config.mjs`: Next.js and TypeScript lint rules.
- `next.config.ts`: Next.js configuration and Tailwind CSS Turbopack loader.
- `package.json` / `package-lock.json`: npm scripts and locked dependencies.
- `next-env.d.ts` / `.next/`: generated Next.js types and build output; ignored
  by Git and regenerated by Next.js.

The frontend is separate from the Spring Boot backend. Application features
will be added in later tasks.
